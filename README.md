# AuctionHouse

GUI-аукцион для Paper/Purpur 1.21.11. Три команды, всё остальное — кнопками в окне.

## Возможности

- Каталог-двойной сундук: 45 лотов на странице, стеклянные стрелки «Назад / Вперёд», счётчик страниц
- Лот — живой предмет (видны чары и название) + приписка: цена, продавец, время до конца
- Покупка через окно подтверждения с показом комиссии, защита от двойной продажи
- Поиск по названию, материалу и нику: командой или кнопкой-компасом (запрос пишется в чат)
- Категории: Все, Блоки, Инструменты, Оружие, Броня, Еда, Зелья, Зачарованное, Разное
- Сортировка кнопкой: Новые, Дешевле, Дороже, Скоро конец
- Склад просрочки: срок лота 7 дней, дальше предмет ждёт на складе, забрать по одному или всё сразу
- Комиссия 10% с продавца только при продаже, выставление бесплатное
- Баланс виден прямо в окне, деньги доходят даже оффлайн-продавцу
- VIP-лимиты слотов через право `auctionhouse.slots.<N>` (LuckPerms)
- Плейсхолдеры PlaceholderAPI: `%ah_active%`, `%ah_mine%`, `%ah_expired%`, `%ah_slots%`
- Звуки интерфейса, всё на русском
- Хранение в `listings.yml` без базы данных, автосейв, анти-дюп на всех операциях

## Команды (всего три)

- `/ah` — открыть аукцион (алиасы: `/auction`, `/auctionhouse`, `/auc`)
- `/ah sell <цена>` — продать предмет в руке, пример: `/ah sell 1500`
- `/ah search <текст>` — поиск, пример: `/ah search алмаз`

Права: `auctionhouse.use`, `auctionhouse.sell`, `auctionhouse.search` (все по умолчанию у игроков).

## Зависимости

- Обязательно: Vault + экономика (например EssentialsX)
- По желанию: PlaceholderAPI, LuckPerms

## Установка

1. Положить `AuctionHouse-X.X.X.jar` в `plugins/`
2. Перезапустить сервер
3. В консоли должно быть `AuctionHouse enabled: tax=10.0%, slots=100...`
4. Настройки: `plugins/AuctionHouse/config.yml`

## Сборка

```bat
.\gradlew.bat build --no-daemon
```

Нужны Java 21, Paper API `1.21.11-R0.1-SNAPSHOT`, VaultAPI (подтянутся сами через Gradle).

Готовый jar: `build/libs/AuctionHouse-X.X.X.jar`.

## Конфиг (основное)

- `economy.tax-percent: 10.0` — комиссия при продаже
- `economy.min-price / max-price` — границы цены
- `listings.max-per-player: 100` — слотов по умолчанию
- `listings.duration-seconds: 604800` — 7 дней жизни лота
- `listings.blocked` — запрещённые к продаже блоки
- `listings.blocked-worlds` — миры, где `/ah sell` запрещён
- `gui.sounds` — звуки, `gui.default-category` — стартовая категория
- `general.announce-min-price` — анонс дорогих лотов (0 — выкл)
