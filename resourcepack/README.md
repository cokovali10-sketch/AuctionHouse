# AuctionHouse — dark-fantasy gold resource pack (optional)

Server-side GUI works WITHOUT this pack (Strategy A).
With the pack (Strategy B assets): gold frames, buttons, dividers.

## Install

1. Zip the `resourcepack/` folder contents (pack.mcmeta at zip root).
2. Upload to a file host, put the link into `server.properties`:
   `resource-pack=<url>` (+ `resource-pack-sha1` recommended).
3. Players accept on join. Without the pack everything still works,
   just with vanilla item icons.

## Files

- `panel.png` — menu background tile (256x128)
- `button_normal/hover/disabled.png` — button states (120x20)
- `divider.png` — section separator
- `manifest.json` — FORGE asset manifest (ids, sizes, license)
- `pack.mcmeta` — pack_format 48 (1.21.11)

Generated by FORGE AAA Interface Engine (PIL, procedural, free to use).
